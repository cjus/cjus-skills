### What is working well

- `source_file` traverses directory components through held file descriptors with O_NOFOLLOW,
  opens the final file without following links, and validates the opened descriptor before
  and after reading. The final-file and ancestor-directory replacement tests both fail closed.
- `environment` preserves the worker's installed RUSTUP_HOME, including the conventional
  default location, while setting a separate session Cargo home and disabling auto-install.
  It does not inherit the operator's Cargo configuration or registry credentials.
- The session lock covers source synchronization, toolchain/cache identity, command execution
  and result recording. The command inherits the lease descriptor, and normal descendants
  are stopped before the supervisor releases the lease. Concurrent-job tests exercise a
  mutually exclusive target marker and verify stale source removal.
- The real dependency-free Rust test uses an already installed toolchain, builds offline,
  demonstrates a Fresh second build, verifies changed source output, and verifies cache reset
  when the toolchain-file identity changes. The follow-up portable launcher still exercises
  rustup through the fixture RUSTUP_HOME; it does not bypass the environment fix.
- The CLI integration now proves that a failed build followed by a successful build uses one
  still-running worker. Documentation keeps explicit `down` separate from jobs and PR close,
  with independent maximum-lifetime cleanup described as a backstop.
