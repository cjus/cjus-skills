## Noted, deliberately not acted on

A two-member **loose** group is close to a null set: if doing A puts you inside a file B names,
that file is common to both and the group is strict. Loose is therefore really about three or
more members with pairwise but not global overlap, which gives its "three members preferred"
guidance a structural reason on top of the attention-cost one. Harmless, and writing it down
would be new scope.
