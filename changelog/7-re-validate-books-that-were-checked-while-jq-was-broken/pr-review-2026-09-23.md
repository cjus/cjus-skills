### Important

🟡 **The rewritten warning folds a loud failure into a list of silent ones**

📍 Location: `plugins/bookcraft/README.md:355`, quoted again in
`changelog/7-.../pr-summary-2026-09-23.md § Code examples`

**What I see:**

> a folder graded in a weaker mode than it declares **still exits 0** with the provenance sweep,
> the suggested-reading requirement and the overview and glossary cross-checks all off, tags
> inferred rather than required, **and the narration rules applied in place of its declared
> profile**.

**The risk:** the first four items are silent; the fifth is the opposite of silent. When a
guide-profile book is graded under the narration rules it does not exit 0 — it fails on every
construct the profile exists to allow. That is not a guess: `guide-under-narration` is the same
chapters as `guide` with the profile line removed, and I re-ran it at this commit for exit 1 on
five lines. `check-book.sh:1167-1171` says so in its own words: *"the profile is the half that
fails loudest: without jq the declaration reads as absent, the narration rules apply, and a guide
book fails on every H3 and every callout it was written to carry."*

So the section now tells a reader that a downgraded guide book slips through quietly, two
paragraphs above the entry that demonstrates it does not. A reader who hits a screen of failures
on a guide book under a broken `jq` will be looking for a regression rather than reading the
error the guard prints. This is the only place where the tightening I asked for made the text
less true than the phrase it replaced.

**Suggested fix:** split the two cases, since they fail in opposite directions.

```markdown
A run that disagrees with this table is either a regression or a fixture edit, and it is worth
knowing which before changing anything. **Read the mode line, not only the exit code:** a
narration book graded in a weaker mode than it declares still exits 0 with the provenance sweep,
the suggested-reading requirement and the overview and glossary cross-checks all off, and tags
inferred rather than required. The filename, ordering, heading and prose sweeps run either way,
which is what makes the downgrade easy to miss. A guide book fails loudly instead, because the
narration rules apply in place of its declared profile and reject every construct the profile
exists to allow. A `jq` that is present and will not run is the case the guard catches; a `jq`
that is simply absent downgrades the same way by design, and says so in a note.
```

The same clause is quoted in the PR summary's `## Code examples`, so both move together.

**Learning note:** a list is an implicit claim that its items are the same kind of thing. When one
member behaves oppositely, the list does the misleading rather than any single word in it — which
is why "name what is skipped" is only half the fix; the other half is keeping the naming sorted by
failure mode.

### Suggestions

🟢 **The measured line is presented as printed output, but it is a reordered excerpt**

📍 Location: `CHANGELOG.md:27-29` ("prints `tagged: 2/2 (inferred)  provenance: off …`"), the same
line at `PLAN.md:114` and in `pr-summary § Code examples`

**What I see:** the line is quoted as what the run prints. What it actually prints is:

```
profile: narration    chapters: 2    content-checked: 2    tagged: 2/2 (inferred)    prose: 570    structure: 298    overview: 0 (off)    provenance: off    suggested reading: off    glossary: none    folder: fixtures/fence
```

Same five figures, different order, with six more fields between them.

**The risk:** small, and only for the next person who tries to reproduce it. The reconstruction is
not findable with `grep` against a real run, and a record whose headline is "Measured, not
inferred" invites exactly that literal check.

**Suggested fix:** either quote the mode line whole, or introduce the condensed form as one —
"the mode line reads, in part: …". The second is fine, and shorter.

**Learning note:** a fenced block sets an expectation of verbatim. Condensing inside one is a
small tax on whoever reproduces it later, and it is free to avoid.
