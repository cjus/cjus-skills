# Figures

The figure pass's record for the guide fixture (`makebook/SKILL.md § Deciding where a figure
helps`). `makebook/fixtures/bind/run.sh` binds this book once with this file and once without
it, and only the bind without it may warn that the figure decisions were never recorded.

## Placed

- **Chapter 1, `the-two-profiles.svg`** ("How a profile is chosen"). Two rule sets, each with
  the reader it serves, is a comparison with two sides, and the prose asks the reader to hold
  both at once.

## Passed over

- **Chapter 2.** The split between checkable and readable rules is a distinction, which prose
  carries better than a box around each half.
- **Appendix 1.** It is a list of four labels, and a figure would restate it.

`slides/` holds lesson-script slides, which are teaching aids rather than figures of the
argument, so nothing here decides them.
