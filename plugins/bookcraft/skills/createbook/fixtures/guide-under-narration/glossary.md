# Glossary

**profile** (ch. 1) The rule set a book's settings file names, absent meaning the
narration rules every book was written under before profiles existed.

**callout** (ch. 2) A labelled block quote from a fixed set, marking what kind of
sentence a passage is for a reader who is scanning rather than reading.

**`profile`** (ch. 1) The `book.json` key that names the rule set, written as a
code span here so the glossary's sorting and rendering are exercised by the fixture.

**appendix** (ch. 1) A chapter-kind file holding reference matter, bound after the
chapters and before the glossary.
